# modelport

modelport is an open-source ML platform where a data scientist puts a model into production with one command: distributed training on Ray, an evaluation gate, online serving with a canary, and monitoring with drift alerts. Everything runs on one local Kubernetes cluster (kind) and comes up with `make up`.

**Status: under construction.** Nothing here is usable yet; see [CHANGELOG.md](CHANGELOG.md) for progress and [docs/adr/](docs/adr/) for the architecture decisions.

modelport is a development environment, not a production platform. Licensed under Apache-2.0 (see [LICENSE](LICENSE) and [NOTICE](NOTICE)).
