# ADR-0012: Use Helm v3.22.1, not Helm 4

- Status: Accepted
- Date: 2026-11-14

## Context

Helm v4.3.2 was released on 2026-11-13, the day before this design. The Airflow chart states a Helm 3 minimum (3.19.0); the sibling project `ray-slurm-vs-kuberay` proved v3.22.1 on GitHub runners.

## Decision

Pin Helm v3.22.1. Moving to Helm 4 is a separate PR that must pass the smoke CI.

## Consequences

- No surprises from a one-day-old major version.
- A future ADR records the switch.
